What's new

Changes to the Plorea API, in the order integrators saw them, and changes to these docs. The newest entry is first. The date is the day the change was observed or announced, not a release date from Plorea.

Verified We saw this on the wire, in test or production. Stated by Plorea Plorea told us. We could not test it.

October 2026

2026-10-10

  • Docs: Visa, Mastercard and American Express test cards, each with a 3-D Secure 2 card for the challenge. See Testing.
  • Docs: the site is published. It covers the API as of this date.

2026-10-06

  • Delete a stored card. DELETE /payment-methods/{id} works in test. Production is not observed yet. The method becomes cancelled. A card that an active or trialing subscription uses is refused with 400. Until 2026-10-05 the route was missing and answered a bare 404. Verified See Delete a card.

2026-10-01

  • Pause and resume. PATCH /subscriptions/{id} accepts status: "paused", and status: "active" with a future nextChargeAt to resume. A trialing subscription cannot be paused. Verified No charge was seen after a resume yet. Open question See Pause and resume.
  • New status past_due. A failed scheduled charge sets past_due, fills failureReason and moves nextChargeAt to the retry. Seen in production. Verified See Failed charges and dunning.
  • First subscription.charge_failed delivery. The event is not in Plorea's published catalogue. Verified See Webhooks.

September 2026

2026-09-30

  • Merchant on card setup. Both card setup flows accept merchantOrgNr and merchantName. 3-D Secure then shows the company's name. Stated by Plorea See Storing cards.

2026-09-22

  • merchantOrgNr on subscription reads. GET /subscriptions/{id}, the list and the charges envelope return it. The merchant name and email are still not returned. Verified

2026-09-21

  • A subscription can bill for another company. Send merchantOrgNr on create. Verified See Subscriptions.

2026-09-19

  • POST /payments/session matches card setup for embedded and native checkout. Verified See Embedded and native checkout.
  • The refund and cancel 401 is gone. Verified Always send X-Environment: a refund without it still goes to live. See Refunds and cancellations.

2026-09-17

  • Embedded and native checkout. Web Drop-in with 3-D Secure, and native Drop-in on a device, work end to end. Verified See Embedded and native checkout.

2026-09-15

  • Capture is automatic. There is no capture endpoint. Stated by Plorea

2026-09-09

  • A declined payment reports failed, never refused. Verified See Payment lifecycle.
  • Reactivating a cancelled subscription is fixed. Verified

Older behaviour, with the evidence for each claim, is in Verified behaviour.
